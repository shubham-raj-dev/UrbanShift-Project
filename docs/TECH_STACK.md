# Tech Stack

UrbanShift is a modern Full-Stack web application utilizing the following technologies:

## Frontend
- **React 18**: Core UI library.
- **React Router DOM**: Client-side routing.
- **TailwindCSS & Vanilla CSS**: Styling framework and custom UI elements.
- **Firebase**: Google OAuth authentication.
- **React Toastify**: In-app notifications.
- **Vercel Analytics & Speed Insights**: Performance monitoring.

## Backend
- **Django 5.x**: Core Python backend framework.
- **Django REST Framework (DRF)**: API creation and management.
- **SimpleJWT**: Token-based authentication.
- **Django Channels & Daphne (ASGI)**: WebSocket handling for real-time chat.
- **Cloudinary Storage**: Persistent media hosting for images.
- **Razorpay**: Payment gateway integration.
- **Brevo SMTP**: Transactional email sending.

## Infrastructure & Database
- **PostgreSQL (Neon)**: Primary relational database, serverless and highly scalable.
- **Redis**: In-memory data structure store used as the Channel Layer for WebSockets.
- **Vercel**: Frontend hosting and CI/CD.
- **Render**: Backend web service and Redis hosting.
